## Q02 — Accountability 與治理責任

![Original question](../assets/mistakes/Q02_source_image_7.png)

### Answer Summary

| Item | Details |
|---|---|
| Correct Answer | **A. accountability** |
| Tested Concept | Microsoft Responsible AI principles |
| Question Keyword | `governance and organizational principles`、`ethical and legal standards` |
| Related Knowledge | [[../knowledge/01_Responsible_AI#六大原則|Responsible AI：六大原則]] |
| Mistake Type | Concept confusion |

### Why the Correct Answer Is Correct

題目問哪個原則要求建立治理與組織責任，使人類對 AI 系統負責並保有監督。這最直接對應 **Accountability**。Microsoft 的正式描述是由人對 AI 系統負責，並建立讓人類維持控制的 oversight。

### Option Analysis

| Option | Correct? | Reason |
|---|---:|---|
| A. **accountability** | Yes | 著重責任歸屬、治理、監督與組織控制，正中題目關鍵字。 |
| B. **fairness** | No | 著重公平分配機會、資源與資訊，以及不同群體間的不合理差異。 |
| C. **inclusiveness** | No | 著重讓不同能力與背景的人都能參與並受益。 |
| D. **transparency** | No | 著重讓人理解系統的能力、限制與行為，不等於指定治理責任。 |

### Related Knowledge

參見 [[../knowledge/01_Responsible_AI#具體情境|Accountability 情境]] 與 [[../knowledge/01_Responsible_AI#Comparison / Common Confusions|Transparency vs Accountability]]。

### Current Microsoft Context

- **Current terminology:** **Accountability**。
- **Legacy / exam-bank terminology:** 本題用語仍與目前六大原則一致，不需轉換。
- **What to answer if this wording appears on an older question:** 出現 governance、oversight、organizational responsibility 或「誰負責」時，選 **Accountability**。

### Exam Takeaway

> **Transparency** 說清楚；**Accountability** 指定誰負責、誰監督。
